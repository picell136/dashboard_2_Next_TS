# dashboard_2_Next_TS

Аналитический дашборд на **Next.js**, **TypeScript** и **Tailwind CSS**.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Что внутри

- боковое меню и адаптивная шапка
- KPI-карточки, график выручки, каналы трафика
- таблица заказов с поиском
- демо-данные в `src/lib/data.ts`
